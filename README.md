# Dynamic Castle New Tab Page

In this project, I am making a new tab page which has a centerpiece of a interactive castle model. The accents of the page, like the title, shortcuts, and search bar will change color based on the time of day, adding the dynamic aspect to the project. I designed the castle model in Blender, so this project is a integrated fusion of programming and 3D modeling. I hope you enjoy it!!!

**View the project here:** https://harpaavan-s.github.io/new-tab/

## Tech Stack

**Built with:** HTML, CSS, JS, Blender

1. HTML was used to build the basic structure of the page, such as writing the title text and shortcuts. It was also used to import the model through model viewer into the webpage.

2. CSS was used to style the page, such as positioning the text and shortcuts, as well as positioning the castle model.

3. JS was used to change the colors of the text, search bar, and shortcuts based on the time of day.

4. Blender was used to actually create the model, which I then imported into my browser with coloring. 

## Features

The page is quite simple but packs a lot for a new tab page:

1. Title text: The title text has a simple "Lock In" phrase at the top is a nice cursive looking font.

2. Widgets: There are 5 custom widgets each with hover effects. These are set to just my own personal thing, so that they are convenient for my own use. They are mainly just to like my emails and my school portal. They cannot be adjusted to your own thing. 

3. Search Bar: There is a search bar which you can use to search the web.

4. **Dynamic Colors:** The colors of the title text, search bar, and shortcuts will change color based on the time of day, and you can see that below.

5. **Interactive Castle:** In the middle there is a floating island with a intricate castle on there. The model spins around by itself, but also has an interactivity feature to it, so you are able to spin around by interacting with it. Check it out as it is the biggest part of this project.

## Dynamic Features

The color accents of the page will change color based on the time of day:

1. In the morning from 6 - 10 AM, all accents will be a light redish-pink color. ![README Files/image.png](<README Files/image-1.png>)

2. In the afternoon from 11 AM - 4 PM, all accents will be greenish-cyan color. ![README Files/image-1.png](<README Files/image-2.png>)

3. In the evening from 5 - 9 PM, all accents will be a pinkish-magenta color. ![README Files/image-2.png](<README Files/image-3.png>)

4. During the night from 10 PM - 5 AM, all accents will be a purplish-indigo color. ![README Files/image-3.png](<README Files/image-4.png>)
