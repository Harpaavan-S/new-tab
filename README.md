# Dynamic New Tab Page

In this project, I am making a dynamic new tab page, which will change based on the time of the day. Currently, I have made a new tab page with a title text and 4 shortcuts that I frequently use. I have also added an animated gradient background. Depending on the time of day, the background and text color will change color. 

**View the project here:** https://harpaavan-s.github.io/new-tab/

## Tech Stack

**Built with:** HTML, CSS, JS

1. HTML was used to build the basic structure of the page, such as writing the title text and shortcuts. 

2. CSS was used to style the page, such as positioning the text and shortcuts, as well as animating the gradient background to loop. I also created the classes for the different times of the day.

3. JS was used to detect the time of day and add the appropriate class to the body of the document.

## Features

The page will change color based on the time of day.

1. In the morning from 6 - 10 AM, the gradient will be a sunset color and the text will be light red. ![README Files/image.png](<README Files/image.png>)

2. In the afternoon from 11 AM - 4 PM, the gradient will be a sky blue color and the text will be dark blue. ![README Files/image-1.png](<README Files/image-1.png>)

3. In the evening from 5 - 9 PM, the gradient will be a dark purple color and the text will be light purple. ![README Files/image-2.png](<README Files/image-2.png>)

4. During the night from 10 PM - 5 AM, the gradient will be navy and the text will be light gray. ![README Files/image-3.png](<README Files/image-3.png>)

I will be adding more features to this later in the future, however this what I have for the initial ship.
